# Retail-Sales-Analysis
Retail Sales Analysis Project using MYSQL , Flask and Power BI.

# Project Overview
- Manages and analyzes retail sales data.
- Provides customer , product , and sales information.
- Generates sales and product-wise reports.
- Visualizes data through dashboards.

  # Technologies used
  - MYSQL and SQL for database management.
  - Python Flask for the web application.
  - HTML and CSS for the dashboard interface.
  - Power BI for data visualization.
 
    # Key Features
    - Customer and product management.
    - Sales transaction management.
    - Sales and product sales reports.
    - Interactive data visualization.
